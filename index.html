Nebular Launcher v1.0.0

DaCoolProject released this · 2026-08-20

The complete Nebular Launcher — download, unzip, and open index.html in any modern browser. No install, no server, everything runs locally.

Which build should I get?

  • With games — the full launcher with all 11 games and apps bundled in. Grab this if you want everything ready to play offline.
  • No games — just the launcher shell (about 25× smaller). Add games later straight from the built-in Game Downloader / store.

Bundled in the "with games" build

BrickBox · Calculator · Eaglercraft · Flappybird · Nebular Invaders · P2P Tic-Tac-Toe · Paint · Polytrack · Race Car · & more

🛡 Both builds ship as a protected build — the launcher and the bundled game logic are obfuscated. Tuned to stay fast: no runtime slowdown in-game.
